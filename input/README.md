# 統一輸入資料夾

所有待審資料放這裡，每個案件一個子目錄：

```
input/
├── {案件名}/
│   ├── 平面圖.dxf           — 主圖面（單張案件放這裡就好）
│   ├── drawings/           — 多張圖時改放這裡（逐層或依專業分圖）
│   │   └── *.dxf
│   └── 審查依據文件         — 使用執照、室內裝修（合格證明）申請書、面積計算表、圖例表等佐證文件
├── 範例/                    — 交付物格式基準與範例圖面（只讀）
│   ├── 複合用途建築物及樓層屬性檢討-範例.pdf
│   ├── 第一階段-複合用途及樓層屬性檢討-格式範本.xlsx
│   ├── 第二階段-設置標準檢討-格式範本.xlsx
│   ├── 室內裝修表單範本/     — 建築物室內裝修 E1 系列空白官方表單（.doc 原件＋.md 轉錄）
│   ├── 楷得立消防設備圖說.dxf                — 範例圖面（非格式範本）
│   └── C686403…_楷得立消防設備圖說.dwg       — 同一張圖的 DWG 原件，AI 讀不了，僅供對照
└── 法規/
    └── 法條清單.pdf        — 核對用法條清單（有具體來源的條文彙編）
```

兩種擺法工具都吃得下——`case.json` 的 `source_drawings[].path` 記的是實際路徑，
沒有硬性命名規定。單張圖用 `平面圖.dxf`，多張圖用 `drawings/`，擇一即可。

**使用執照**與**室內裝修申請書**為 `/plan-intake` 證照文件萃取（`use_permit`／`interior_renovation`／`change_of_use`）
的必要輸入，缺件時 §13 適用判斷與主從用途判定將輸出「需人工判讀」。室內裝修申請書（E1-2）等
建管表單的空白官方版本與欄位對照見 `input/範例/室內裝修表單範本/README.md`。

## 各種檔案格式怎麼處理（都不用安裝任何東西）

| 你手上的檔案 | 怎麼辦 |
|---|---|
| `.dxf` | 直接放進來就好——以標準庫解析，零安裝 |
| **`.dwg`** | **AI 讀不了**（二進位專有格式）。跑 `python3 tools/dwg_guide.py check --path input/`，照它印出的步驟用你自己的 CAD 另存成 DXF |
| `.pdf`（使用執照、申請書、審查表…） | 直接放進來，AI 會自己讀 |
| `.docx`／`.xlsx` | 同上，直接放進來 |

DWG 另存 DXF 時記得：**版本選「AutoCAD 2013」或更新**（舊版的中文是 Big5 編碼，圖層名容易變亂碼），
**不要勾選「二進位／Binary」**。四大 CAD（AutoCAD、ZWCAD 中望、BricsCAD、GstarCAD 浩辰）都可以直接打 `DXFOUT` 指令。

### 收到舊版（R12／Big5）DXF 也沒關係

上面是「品質最好」的建議，不是硬性要求。實務上送審圖多半是舊版——
`input/範例/楷得立消防設備圖說.dxf` 就是 R12（AC1009）、標頭沒有 `$DWGCODEPAGE`、
圖層名為 Big5。解析器會比對候選編碼自動判定，並在圖面警告區說明它選了哪個編碼、
有多少字元無法還原。看到那則警告不必重新匯出，**但中文圖層名要人工掃一眼**。

### 消防設備符號是「圖塊」，數量從圖塊統計看

真實圖面上偵煙探測器、緊急照明燈、揚聲器等都是圖塊（DXF 的 `INSERT`）。
跑 `python3 tools/dxf_parse.py --input {圖檔}` 會列出依圖層與圖塊名彙總的插入點數量，
可直接拿來對照「應設 vs 實設」。名稱以 `*` 開頭的匿名圖塊是 CAD 內部產物
（舊版 DXF 用它表示填充線與標註），已自動略過。
**圖塊插入點數不等於實際設置數量，仍須人工核對。**

轉檔而來的圖面，`case.json` 對應欄位會標 `source: derived`，可讀性最高只到 B 級——轉檔會改動圖層命名與圖塊，需人工複核。
轉檔產物一律寫到 `output/`，**`input/` 只讀不改**。

- DXF 圖面與審查依據文件 → 由 `/plan-intake` 讀取，產出 case.json 到 `output/`
- 法條清單 PDF → 由 `/regulation-intake` 結構化為 `rules/equipment_rules.json` 與 `rules/regulation-checklist.html`（先紅再綠測試通過後才可使用）
- 輸入檔案只讀不改；所有產出一律寫到 `output/`
