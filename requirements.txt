# Fire Review — 選用套件（審圖主線不需要任何一項）
#
# 本倉庫預設什麼都不必安裝。多數使用者只裝了一個 AI 桌面版就開始用，
# 沙盒與安全限制讓 pip install 往往失敗——所以審圖主線刻意做成零安裝：
#   · 法規門檻計算與法條查詢  → fire_code_calc.py、regulation_index.py（標準庫）

#   · PDF／DOCX／XLSX 判讀    → 由 AI 直接讀取檔案
#
# 以下三個套件只影響少數交付物格式，且每項都有替代路徑
# （跑 python3 tools/check_env.py 會列出來）。裝不起來不影響審圖。
#
# 想一次補齊：bash tools/setup.sh   或   python3 -m pip install -r requirements.txt
