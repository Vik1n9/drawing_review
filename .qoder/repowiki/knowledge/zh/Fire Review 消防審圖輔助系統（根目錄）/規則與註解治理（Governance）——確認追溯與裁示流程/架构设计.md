本模組為純資料目錄，不執行程式邏輯，由外部工具（`tools/pending_review.py`、`tools/verification_sheet.py`、`practice_note_engine.py`）驅動四段式工作流：
- `待確認清單/已裁示/`：存放規則參數 vs 現行條文比對產出的差異清單（JSON），每筆 finding 含 `id`、`status`、`auto_fix`（測試與參數修正建議）、`manual_steps`，供使用者逐則裁示。
- `核定表/`：由 `verification_sheet.py export` 產出 HTML 核定表，僅在紙本簽名流程時使用。
- `核定紀錄/`：存放 `results-{YYYYMMDD}[-{規則檔}].json`，格式為 `{verified_by, verified_date, evidence?, results: [{rule_id, result, note?}]}`，是 `apply` 回填 `verified: true` 的唯一輸入來源。
- `註解紀錄/`：由 `practice_notes/active/` 的註解在 `apply` 時自動產生 Markdown 追溯檔。

依賴方向單向：外部工具讀取本目錄 JSON → 寫回 rules/*.json；本目錄不反向呼叫任何程式碼。裁示狀態以 `pending_review.py` 的 `status/list/decide/apply` 子命令串接，`apply` 強制先紅再綠（改測試 expected → 轉紅 → 改參數 → 轉綠）才允許回填。
