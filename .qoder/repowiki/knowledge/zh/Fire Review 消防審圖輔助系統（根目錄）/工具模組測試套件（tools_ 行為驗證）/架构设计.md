測試以 Python unittest.TestCase 為統一框架，每個 test_*.py 對應一個 tools/ 下的模組或功能域，採用「一文件一主題」的組織方式。測試結構分為兩層：
- 單元層：直接 import tools.* 並用 unittest.mock.patch 替換外部相依（如 subprocess、guard.home_index_path、check_env.probe），確保測試不依賴網路與真實家目錄。
- 整合層：透過 make_release.build(stage_only=True) 產出實際安裝包，再以 subprocess 執行 tools/onboarding.py 等 CLI 驗證端到端流程。
所有測試使用 tempfile.TemporaryDirectory() 建立隔離倉庫根目錄，由 helper 函數（如 write_tree、make_repo、build_dxf）生成最小可用資料結構，避免讀取真實倉庫內容。對真實 graph.json 的測試會先檢查 REAL_GRAPH 是否存在，不存在則 SkipTest。
