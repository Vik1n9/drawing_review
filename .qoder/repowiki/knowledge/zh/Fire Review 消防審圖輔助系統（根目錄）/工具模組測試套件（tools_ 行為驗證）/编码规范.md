- 每個測試類別繼承自 unittest.TestCase，並在類別 docstring 中說明該組測試守住的契約或行為假設。
- 外部相依（subprocess.run、guard.home_index_path、check_env.probe、os.getcwd 等）一律透過 unittest.mock.patch 在 setUp 或測試方法內替換，確保測試不碰真實家目錄與網路。
- 臨時倉庫根目錄由 tempfile.TemporaryDirectory() 建立，並搭配 write_tree / make_repo / build_dxf 等 helper 函數產生最小可用 JSON 與 DXF 內容。
- CLI 測試統一透過 io.StringIO 截獲 stdout/stderr，並斷言返回碼為 0（成功）或 2（待處理/拒絕）。
- 對真實圖譜的測試會先檢查 REAL_GRAPH 路徑是否存在，不存在時以 unittest.SkipTest 跳過，避免 CI 因缺少產物而失敗。
- 測試斷言使用具體的訊息字串說明預期行為，特別是錯誤訊息必須包含使用者可操作的關鍵字（如「二進位」「DXF」「safe-update.md」）。
