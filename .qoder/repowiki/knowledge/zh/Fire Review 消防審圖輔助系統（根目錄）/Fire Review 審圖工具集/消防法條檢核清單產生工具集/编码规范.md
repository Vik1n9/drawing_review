- 每個腳本皆以 `#!/usr/bin/env python3` 開頭，並透過 try/except ImportError 同時支援從專案根目錄與直接進入 tools/ 目錄兩種執行方式來匯入 `tools.console.force_utf8_output`。
- CLI 一律使用 `argparse.ArgumentParser` 定義 `--results` / `--case` / `--output` 等參數，未指定 `--output` 時預設寫入與輸入同目錄且檔名由案件名稱衍生。
- 檢核狀態統一使用四值 enum：pass（☑ 符合）、fail（☒ 不符合）、manual（⚪ 需人工判讀）、na（— 不適用），並在 HTML 與 Excel 中以相同符號與底色呈現。
- JSON 輸入/輸出一律以 `encoding="utf-8"` 開啟，避免 Windows 環境下的編碼問題。
- 錯誤處理採用明確的例外類型（如 `ChecklistInputError`）或 `sys.exit` 搭配人類可讀訊息，而非拋出原始異常堆疊。
