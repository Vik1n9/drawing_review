執行前需確保 `tools/setup.sh` 已安裝 openpyxl（`bash tools/setup.sh` 或 `python3 -m pip install -r requirements.txt`）。常用命令：
- `python3 tools/article_checklist.py --case output/case.json` 產生 `check_results.json`
- `python3 tools/checklist_html.py --results output/check_results.json` 產出 HTML 清單
- `python3 tools/review_checklist_xlsx.py --results output/check_results.json` 產出雙分頁 Excel
- `python3 tools/standard_checklist_html.py --input rules/checklists/標準表.xlsx --answers answers.json` 將標準表轉為 HTML。
