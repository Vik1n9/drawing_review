依內政部九十九年十二月二十三日台內營字第○九九○八一○三四五號令修正（表單自載之修正註記）。

**只讀不改**（`input/` 全域規則）。這些是空白表單，不是已填寫的實際案件資料。

## 與消防審圖的關係

E1-1 與 E1-6 的審查項目均含 **【消防審查合格證明】** 一列——室內裝修案的消防審查結果是建管
審查／竣工查驗的必要書件，本系統產出的缺失清單與檢核表即為該證明的前置作業。

E1-2（申請書）是 `skills/plan-intake.md` 第二步半「證照文件萃取」所稱的**室內裝修（合格證明）
申請書**的官方表單，也是 §13 新舊標準適用判斷的必要輸入。欄位對照如下：

| 表單欄位（E1-2） | case.json 欄位 |
|-----------------|----------------|
| 【建築物使用執照號碼】 | `use_permit.permit_no` |
| 【裝修樓層】、【裝修位置】 | `interior_renovation.floors` |
| 【申請樓地板面積】（m2） | `interior_renovation.area` |
| 【變更後建築物用途】 | `interior_renovation.post_renovation_use`、`change_of_use.after` |
| 【原建築物用途】 | `change_of_use.before` |
| □變更使用／□未變更使用 | `change_of_use.occurred` |

E1-1 表頭的 □新建／□增建／□修建／□改建 與 □【併變更使用執照申請】勾選，對應
`interior_renovation.works_type`。

**現行 schema 尚無對應欄位者**（有值也無處可寫，需要時走 `/red-green` 擴充 schema 再入庫）：
E1-2 的【原有樓地板面積】、【合格證明字號】、【核發日期】、【歷次室內裝修合格證明字號】。

上表僅為**欄位名稱對照**，實際萃取值一律須經 `plan-intake` 第三步人工確認關卡；
表單欄位空白或字跡不清者標「需人工判讀」，不得以預設值填充。

## 轉錄方式

`.doc` 為 Word 97 複合文件格式（Big5／cp950 編碼），一般轉檔工具未必能載入；
本轉錄係以 OLE 串流 ＋ 分段表（piece table）直接解析 WordDocument 串流的文字內容。
`.md` 檔的「轉錄註記」段落載明各表不確定之處（主要是表格儲存格合併關係）。
