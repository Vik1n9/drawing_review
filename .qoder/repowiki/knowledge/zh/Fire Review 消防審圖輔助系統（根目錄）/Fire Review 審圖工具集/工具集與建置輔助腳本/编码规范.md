- 所有 Python 工具開頭先嘗試 `from tools.console import force_utf8_output`，失敗時退回 `from console import force_utf8_output`，然後立即呼叫 `force_utf8_output()` 確保中文輸出不中斷。
- CLI 一律使用 `argparse` 搭配子命令（subparsers），每個子命令對應一個 `cmd_xxx(args)` 函式，並在 `main()` 或 `build_parser()` 中註冊參數與預設值。
- 錯誤處理採 fail-open 策略：解析失敗、格式未知、任何例外一律放行或回傳安全預設值（如 `guard_hook.py` 一律 EXIT_ALLOW=0），避免工具本身阻礙正常工作流程。
- JSON 輸入/輸出一律指定 `encoding="utf-8"` 與 `ensure_ascii=False`，確保繁體中文正確讀寫。
- 大型工具內以區塊註解分隔功能區段（如 `# ---------------------------------------------------------------------------` 分隔保護範圍、基準、備份庫、診斷、snapshot、diff/restore、commit、install、CLI），便於定位邏輯。
