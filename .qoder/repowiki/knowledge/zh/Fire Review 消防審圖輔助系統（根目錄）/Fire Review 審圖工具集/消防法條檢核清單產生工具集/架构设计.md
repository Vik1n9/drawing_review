本模組由四個獨立 CLI 腳本組成，各自以 `argparse` 接收參數、讀取 JSON 輸入、寫入輸出檔案，彼此不互相匯入：
- `article_checklist.py`：核心計算入口，呼叫 `fire_code_calc.threshold_results` 對 §14~§31 逐條窮舉，產出統一的 `check_results.json`（含 status: pass/fail/manual/na 與 rule_status: coded/coded_quantity/not_coded）。
- `checklist_html.py`：純 stdlib HTML 渲染器，將 `check_results.json` 轉為帶 CSS 樣式與條號錨點連結的表格。
- `review_checklist_xlsx.py`：使用 openpyxl 產出兩分頁 Excel（明細 + 摘要統計），與專案內其他 stage_report 共用排版常數風格。
- `standard_checklist_html.py`：將消防人員提供的第 14~31 條 Excel 標準表解析為 `Checklist` dataclass，再依答案 JSON 在對應檢查格畫紅勾，輸出固定版面 HTML。

依賴方向單一向下：四個腳本皆依賴 `tools.console.force_utf8_output` 統一 UTF-8 輸出；`article_checklist.py` 額外依賴 `fire_code_calc` 與 `rules/equipment_rules.json`、`rules/regulation_articles/*.json`；其餘三個僅依賴 Python 標準庫或 openpyxl。所有輸出檔名預設與輸入同目錄，可透過 `--output` 覆蓋。
