# 審圖修正筆記（累積確認的通案修正）

本檔記錄**使用者（消防專業人員）已明確確認、可供未來案件重用的修正**。
`/first-stage-review` 與 `/stage-two-review` 在檢視任何案件文件之前**必須完整讀取本檔**。

## 本檔的法律位階（對應審圖最高原則 1、6）

本檔記載的是實務判斷慣例與輸出格式約定，**不是法條原文**。涉及法規解釋的條目已附條號；
本檔**尚未經 `governance/` 核定流程簽署**，等同 `verified: false`，援引本檔做成的結論
輸出時須附警語「本判斷慣例未經消防專業人員核定，以現行法規為準」。門檻數值一律回
`python3 tools/fire_code_calc.py` 與法條原文核對。

## 使用規則

- 審圖前完整讀取本檔。
- 依每則筆記的「Scope（適用範圍）」判斷是否套用。
- 優先序為：目前使用者指示 → 現行法規與本案核准文件 → 本檔中 `Status: Active` 且適用的
  筆記 → skill 其餘規則 → 舊範例與專案流程筆記。
- **不得刪除既有筆記。** 新規則以追加方式建立；相同規則僅更新 `Last confirmed`，
  並補充新增的適用範圍或依據。
- 新規則取代舊規則時，先追加新筆記，再**僅修改**舊筆記的 `Status` 與 `Notes`，
  標記為 `Superseded` 並指向新筆記。
- 不得加入猜測、暫定建議、未解決的疑問，或未經使用者確認即推定的修正。
- 不記錄姓名、地址或非必要案件識別資料。
- 記錄新筆記後簡短告知使用者。

## 筆記格式

```
### YYYY-MM-DD — 簡短標題

- Status: Active
- Last confirmed: YYYY-MM-DD
- Error: 原本錯誤的判斷或輸出方式。
- Correction: 使用者確認的正確做法。
- Scope: 適用的案件、文件、欄位或條件。
- Evidence: 使用者提供的依據；若未提供外部依據，填「使用者明確確認」。
- Notes: 必要的例外或與其他筆記的關係；無則填「無」。
```
