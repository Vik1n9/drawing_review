# 使用手冊（給消防專業人員）

不必懂程式，也不必碰 git。整套流程說穿了只有三件事：放圖、跟 AI 說要審哪個案件、收交付物。

- [1. 先拿到這套系統](#1-先拿到這套系統)

- [3. 審一個案件](#3-審一個案件)
- [4. 你會拿到什麼](#4-你會拿到什麼)
- [5. 更新到新版（成果保護）](#5-更新到新版成果保護)

## 1. 先拿到這套系統

兩種取得方式，挑一種就好。

| | 給誰 | 怎麼拿 |
|---|------|--------|
| 線2：安裝程式（建議） | 不必懂 git 的人 | 到 [Releases](https://github.com/Vik1n9/drawing_review/releases) 下載 `FireReview-{版本}-setup.exe`（自解壓縮檔），雙擊執行，自己選一個安裝資料夾 |
| 線1：`git clone` | 技術人員、要送 PR 的人 | `git clone https://github.com/Vik1n9/drawing_review.git` |

沒裝過 Python 也沒關係，安裝程式偵測不到時會自動下載官方安裝程式（會先確認那是 Python 官方
簽章的檔案才執行）。裝完打開資料夾裡的「安裝完成-請把這段貼給你的AI.txt」，照著把那段話貼給
你的 AI，它就會把那個資料夾當成專案資料夾。

> Windows 會跳「已保護您的電腦」的藍色警告。那是因為我們沒有買程式碼簽章憑證，不是它偵測到
> 病毒；點「其他資訊」→「仍要執行」就過了。
>
> 如果防毒軟體直接把它擋掉或刪掉：自解壓縮檔這種格式常被防毒視為可疑（惡意程式也愛用這種殼），
> 企業電腦尤其容易被隔離。這時請改用同一頁的 `.zip`，內容完全一樣，只是要自己選資料夾、
> 自己裝 Python。

## 2. 第一次使用

不論你用的是 Claude Code、Codex、OpenCode 還是別的 AI 工具，載入資料夾後先跑這一行：

```bash
python3 tools/onboarding.py status
```

（Windows 若沒有 `python3`，改用 `python tools/onboarding.py status`）

它會診斷目前狀態，並列出還有哪些步驟待處理。接著跟你的 AI 說「照 `skills/onboarding.md`
帶我開始」，它會依序引導六個步驟：

1. 本機成果保護：確認你的成果不會被更新蓋掉
2. 待確認事項裁示：規則參數和現行條文比對出的差異，逐則由你裁示
3. 法規圖譜：條文關聯，以及你確認過的實務見解
4. 環境工具：這台電腦現在能做什麼，做不到的又要怎麼繞
5. 規則庫健康：自檢與規則測試
6. 操作簡介：`python3 tools/onboarding.py intro`

> 過程中有兩條安全底線。唯讀的檢查，AI 可以直接跑；會改動系統的動作（安裝套件、回填裁示、
> 重建圖譜）一律要先說明並取得你的同意。還有一條沒得商量：AI 不得代替你裁示任何法規事項。

### 不必安裝任何套件

審圖主線用得到的功能，包括法規門檻計算、DXF 圖面標註、PDF／DOCX／XLSX 判讀，全部零安裝。
只有兩階段 Excel 匯出這類少數交付物格式要第三方套件，而且都留了替代路徑：

```bash
python3 tools/check_env.py   # 列出這台電腦現在能做什麼、做不到的怎麼繞
```

躲不掉的前置條件只有 Python 本身。如果它回報「找不到 python3／python」，請先裝 Python
（<https://www.python.org/downloads/>，Windows 安裝時記得勾選「Add python.exe to PATH」）。
在那之前不要讓 AI 用聊天代替法規數值計算：本系統禁止心算，沒有工具就只能做不涉及數值的協助。

## 3. 審一個案件

1. 放檔案：把待審的 `平面圖.dxf` 放進 `input/{案件名}/`，輔助用的 `平面圖.pdf`、申請書、
   審查表等文件也一起放。多張圖可以另開 `drawings/` 子資料夾。
2. 開口：用中文直接跟你的 AI 說「幫我審 {案件名} 這個案件」。
3. 回答關卡問題：過程中它會停下來請你確認面積、用途、構造、樓層、既有設備、§12 主從用途分類。
   這些是關卡，不是選填欄位，AI 不會替你猜。
4. 收交付物：到 `output/` 拿四份檔案，內容見下一節。

想改走 Excel 路線的話，跟 AI 說「走兩階段 Excel 流程」，第一階段產出複合用途及樓層屬性檢討，
第二階段產出設置標準檢討。第一階段沒定案就不能執行第二階段；第一階段結果之後有修正，
第二階段也必須從頭重跑。

### 想查法規時

直接說「查第 24 條」或「排煙設備規定在哪幾條」就行。AI 會先用法規圖譜定位條號與關聯，
再調出條文原文核對，不會憑記憶回答你。

## 4. 你會拿到什麼

| 交付物 | 內容 |
|--------|------|
| `{案件名}-圖面審查.html` | 圖面轉成網頁，缺失位置直接圈在圖上，可點選導覽 |
| `{案件名}-問題清單.md` | 缺失逐項詳列違反法條、應設要求、圖面現況、缺口 |
| `{案件名}-法條檢核清單.html` | §14~§31 逐條打勾表，條號可點進法條原文 |
| `{案件名}-複合用途及樓層屬性檢討.html` | 主從用途與各層樓層屬性檢討表 |

缺失固定分四級，另外還有一類建議：

- `重大缺失`：法定應設的設備類別完全沒設
- `一般缺失`：設備有設，但數量不足或規格不符
- `配置疑義`：數量達標，但配置可能不符法定距離，要在圖面上逐點量測才知道
- `需人工判讀`：現有資料判定不出來，系統不會替你猜
- `建議事項`：沒有強制法源的實務建議，一律標明「無強制法源」

判定「符合」和「不適用／免設」的時候，一樣會留下可覆核的計算過程與條文依據。

> 要看大樣圖或到現場才能確認的項目（防火區劃、排煙開口、夾層面積之類），一律留給你判斷。

## 5. 更新到新版（成果保護）

你的訓練成果只存在你這台電腦，一旦被覆蓋掉就回不來了。更新之前先跑：

```bash
python3 tools/update_guard.py check                     # 唯讀，看有什麼會被影響
python3 tools/update_guard.py snapshot --note "更新前"   # 備份到這個資料夾的外面
```

接著照你當初的取得方式處理：

- 線2（安裝程式）：到 Releases 下載新版，裝到同一個資料夾。安裝程式會先備份，你沒改過的檔案
  直接更新，你改過的檔案一律保住原檔，上游新版另存成 `.上游新版` 讓你自己比對；你新增的案件
  圖面與實務見解完全不動。裝完會留一份「更新報告-日期.txt」。（它是先解壓到暫存區再逐檔判斷，
  判斷跑起來之前，你的資料夾一個位元組都不會被碰到。）
- 線1（git）：先 `python3 tools/update_guard.py commit`，再 `git pull --ff-only`

> 絕對不要讓 AI 用 git 指令幫你「清乾淨再更新」。`git reset --hard`、`git checkout -- .`、
> `git restore`、`git clean`，還有刪掉目錄重新 clone，都會抹掉你累積數月的成果，而且沒提交過的
> 改動連 reflog 都救不回來。安全的程序寫在 `skills/safe-update.md`；Claude Code 另外有 hook
> 會擋下這些命令。

## 6. 疑難排解

**圖面是 `.dwg`？**
DWG 是二進位格式，AI 讀不了。跑 `python3 tools/dwg_guide.py check --path input/`，
它會告訴你怎麼用自己的 CAD 另存成 DXF（`DXFOUT` 指令，版本選 2013 以上，不要勾二進位）。
這樣零安裝，而且 CAD 原生匯出的品質比任何轉檔器都好。

**AI 說某個交付物做不出來？**
跑 `python3 tools/check_env.py`。工具缺套件時一律會給替代路徑，不會靜默失敗：

| 做不到的事 | 替代路徑 |
|------------|----------|
| 兩階段 Excel 匯出（缺 `openpyxl`） | 改用 HTML 版法條檢核清單，內容相同，只是格式不同 |
| 平面圖 PDF 紅圈標註（缺 `pymupdf`，legacy） | 改用交付物①的 HTML／SVG 圖面標註，功能更完整 |
| 二進位 DXF（缺 `ezdxf`） | 請用 CAD 改存 ASCII DXF |

環境裝得起套件的話，可以用 `bash tools/setup.sh` 一次補齊。這是加分項，不是門檻。

**開場說有「待確認事項」，可以先不管嗎？**
可以照常審圖，只是受影響規則的輸出會附上「本參數尚未逐條確認」警語。想清掉就請 AI 把疑義
逐則列給你，你回覆「採納更正／維持現值／另有更正＋正確值」，它會代跑 `pending_review.py decide`
和 `apply --all`。

**AI 直接給我一個法規數字，沒跑工具？**
那違反了本系統的底線。請它改用 `python3 tools/fire_code_calc.py` 重算，並把工具輸出貼進報告。
禁止心算，也禁止憑記憶引法規數值。
